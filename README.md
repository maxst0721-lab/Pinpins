## 🔒 隱私與安全

- **不用註冊、不用登入**。
- **你的資料只存在手機裡**：座標、路徑、照片、歷史紀錄、設定都不會傳給作者或任何伺服器。Pinpins 本身沒有廣告，也不追蹤你的使用情形。
- **會連上網路的只有這幾件事**：
  - 顯示地圖（Google 地圖）
  - 搜尋地名、自動命名時查地名（由手機系統向 Google 查詢）
  - 打開 App 時檢查有沒有新版（向 GitHub 查詢，可以在「⚙️ 系統」關掉）
- 手機的「Google 備份」開著時，Android 可能會把 App 的資料備份到**你自己的 Google 帳號**（這是手機系統的功能，不經過作者）。換手機時不一定會自動還原，建議用 App 裡的「⚙️ 系統 → 💾 備份與還原」自己備份。
- **權限的用途**：定位（地圖上顯示目前位置、懸浮收集的 📍 讀手機現在的位置）、模擬位置（送出你設定的位置）、顯示在其他應用程式上層（懸浮工具與懸浮收集）、通知（飛行中的常駐通知、倒數提醒）、鬧鐘與提醒（倒數準時響）。剪貼簿只在你按「📋 貼上」或懸浮收集鈕時才讀取。
- **請只從這個頁面下載**。從其他地方拿到的 APK 可能被改過；更新時，簽章不同的 APK 也裝不上去。

## 安裝

1. 點開下載的 APK 檔安裝。手機問「是否允許安裝未知的應用程式」時，允許你用來開檔案的 App（例如瀏覽器、LINE 或「我的檔案」）。
2. 打開 Pinpins，允許定位和通知。

更新時直接安裝新版覆蓋，資料都會留著。

## 第一次設定（只要一次）

Pinpins 要設成手機的「模擬位置應用程式」才能飛。第一次打開會提醒，照著做就好：

- 設定 → 關於手機 →（三星多一層「軟體資訊」）→ 連按「版本號碼」7 次（打開開發人員選項）
- 設定 → 開發人員選項 → 選取模擬位置應用程式 → Pinpins

用懸浮視窗（跳躍、種花、定點的懸浮工具）或懸浮收集時，要允許「顯示在其他應用程式上層」。開關按不下去（顯示「受限制的設定」，Pixel 等手機常見）：

- 先試著打開一次 → 設定 → 應用程式 → Pinpins → 右上角 ⋮ →「允許受限制的設定」→ 再回去打開

## 飛行

- 輸入一個座標 = 直飛定點；定點中輸入另一個座標，主鍵變成「換位置」，直接瞬移
- 座標可以寫成 25.0339, 121.5645，也看得懂度分秒（25°02'02.0"N 121°33'52.2"E）、度分、北緯25度2分 東經121度33分、25.0339 N, 121.5645 E
- 輸入地名直接按起飛：自動搜尋並飛過去（取第一筆；想先看結果就按 🔍）
- 長按地圖：選點（飛過去，或加入輸入框）
- 多點有三種飛法（右側按鈕）：
  - 🎮 跳躍：用懸浮視窗手動一點一點跳（照清單的順序）
  - 🌸 種花：自動繞著花點循環（點都在 5 公里內會自動選這個）；雙擊 🌸 可以改繞法
  - -1-2- 照順序：照輸入的順序、用走路速度循環
- 照順序走完一圈會「跳回起點」（不會從最後一點走回去）；想走回去，到左側選單「🌸 種花模式 → 〰️ 照順序」取消勾選
- 跳躍懸浮視窗：點中間的圓點展開面板。藏菇的那一排是燈號（按一下換 🟢 待巡邏 → 🟡 待使用 → 🔴 使用中）、📤 出借中、⚠️ 高風險；最下面一行是 🔒 鎖定、🗺️ 地圖、💾 備註存進座標卡（備註欄會先顯示這一點原本的備註，改好按 💾 取代原本的；只有我的座標裡的點才能存）、複製並記下。拖到下面的 🗑 只關視窗，不會停飛
- 飛行中從別的地方起飛會先問：▶ 取代，或 ⏸ 暫停並改飛（鎖定中不能暫停）。暫停的任務在 🎮／🌸／-1-2- 按鈕上顯示小紅點（定點是上方的 📍），點它可以 ▶ 接續、⇄ 互換或 🗑 清除；按停止時會問要不要一起清除，或改成接續暫停的
- 👀 看看模式：沒在飛時長按右下的起飛鍵切換（按鈕變藍色）。這時我的座標、我的路徑、歷史、地圖選點的起飛都變成「看看」：不會飛過去，而是在遊戲的大範圍地圖打開那個地方；多點會出現跳躍的懸浮視窗，按 ◀ ▶ 換著看。看完多點會自動回到一般起飛，再長按也能切回
- 🔒 鎖定：把位置固定在某個時區的基地，配合遊戲的日期；雙擊鎖定鍵可以改設定
- 鎖定中按跳躍視窗的換點、訪花的補繞：不會解鎖，解鎖後才換過去
- 左上 ✏️：在地圖上手繪路線；＋ 插入打開後先點一個點、再點地圖，新的點加在它後面；橡皮擦點一下刪掉那一點；↶ 退回上一步
- 手繪路線的圖形：左上 ✏️ 進手繪後，雙擊 ＋ 選圖形（圓、三角、四方、螺旋圓、蛇行矩形、星星、愛心）；單指拖曳移動、雙指縮放和旋轉，下面調點數、圈數等，按「✔ 加入」
- 飛行中的小停止鍵太小：左側選單「⚙️ 系統 → 🖥️ 顯示」改成中或大

## 懸浮工具與搖桿

種花、照順序、定點起飛時自動出現。

- 🧰 單擊打開第 1 組按鈕、雙擊打開第 2 組（預設是訪花和搖桿），再單擊收起
- 按住 🧰 拖曳；拖到下面的 🗑 就關閉（不會停飛，點通知叫回來）。搖桿按住左上角的四向箭頭拖曳，拖到 🗑 就收起
- 搖桿：推到外圈就往那個方向一直走（上方 N = 北），移回中間才停；快速點中間 2 下切換成「放手就停」，再點 2 下切回來
- 種花、照順序：暫停時才會出現搖桿；按 ▶ 繼續會回到暫停的地方接著走
- 不想搖桿自己跳出來：左側選單「🕹️ 懸浮工具」取消「暫停時自動顯示搖桿」或「定點時自動顯示搖桿」；之後要用時按 🕹️ 打開
- 📋 剪貼：選分類、打名稱與備註、📷 選照片，再選 📋 記到剪貼簿 或 💾 存進我的座標；名稱空白會自動用地名命名
- 懸浮工具的 🔍 搜尋（在 ℹ️ 資訊下面）：輸入座標或地名（📋 可以貼上），按起飛就瞬移過去定點；種花、照順序中會先問要不要中斷
- 🌸 訪花（種花時）：點路線圖上的花點選要補繞的，按「開始補繞」就跳過去各繞一圈，繞完回到原本的路線
- 🔍 對齊：遊戲切到俯瞰、地圖轉回北方；按花的圖示後拖曳、雙指縮放，讓路線圖和遊戲的花點重疊，再點花點；按地圖圖示可以操作底下的遊戲
- 按鈕放哪一組、外觀、速度檔位：左側選單「🕹️ 懸浮工具」

## 我的座標／我的路徑

- 多點按 💾 儲存：可以存成路徑，或存成多筆座標（⚡ 自動選一次類別、✍️ 手動一筆一筆填）
- 按「選取」後可以「✏️ 改名」：依地名重新編號，或自己取名字自動加 #1、#2…
- 選 🍄‍🟫 藏菇後，下面可以再篩燈號和風險，可以多選
- 🔍 搜尋後，還可以再點分類、燈號、3./0. 縮小範圍（搜尋文字會留著）
- 「我的」清單的 🔍 輸入一個座標：找出同一點的座標、經過這一點的路徑、飛過這一點的歷史；主畫面輸入一個座標時，在路徑裡也會出現「🗺️ 在路徑裡」，點了就列出那些路徑
- 「我的」清單的 🔍 輸入「3.」：找當地現在 3 點多的座標和路徑；「1~3.」= 1 點到 3 點多；前面加「昨／今／明」只找當地日期是台灣昨天／今天／明天的（例如「今5-6.」），單獨打「昨」= 昨天的全部；可以和其他字一起搜（例如「3. 公園」）
- 匯入路徑檔時，可以選「📍 單筆座標」存成我的座標；路徑的「編輯」裡可以把 🌸 種花／〰️ 其他互換
- 路徑卡片 ⋮「⏰ 倒數計時」：選 23 小時或自訂時間，也可以選「🔔 時間到時發出聲音」；卡片上 🔔 = 會響、⏳ = 不響
- 裡面「範例」開頭的點和路徑可以直接拿來試飛，不要時刪掉就好

## 小技巧

- **收集別人分享的座標**：左側選單 → 📋 剪貼簿 → 📥 懸浮收集。在 LINE 等 App 複製座標後，按一下懸浮鈕就收進來
- **懸浮收集鈕長按**：展開 📋 剪貼（替最後收集的那一點加名稱、備註、照片，再記到剪貼簿或存進我的座標）、📖 查看收集、＋ 開新的一組、📍 收集手機現在的位置（和 Google 地圖的藍點一樣，同時複製起來可以直接貼到 LINE）；拖到下面的 🗑 關閉
- **減少位置閃回**：左側選單「📡 防止閃回」→ 關掉「Google 定位精確度」（最有效）；「Wi-Fi 掃描」「藍牙掃描」也可以關。需要導航時再打開
- **換手機**：左側選單 → ⚙️ 系統 → 💾 備份與還原 → 建立備份；新手機裝好 Pinpins 後選「從備份還原」
- 有新版時打開 App 會提醒；也可以到左側選單「⚙️ 系統 → 🔄 檢查更新」
