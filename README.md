# 📍 Pinpins

模擬定位與座標收藏工具。

## ⬇️ 下載

**[下載 Pinpins（最新版 APK）](https://github.com/maxst0721-lab/Pinpins/releases/latest/download/Pinpins.apk)**

目前版本：1.22s ｜ 需要 Android 9 以上 ｜ [所有版本](https://github.com/maxst0721-lab/Pinpins/releases)

## 安裝

1. 點開下載的 APK 檔安裝。手機問「是否允許安裝未知的應用程式」時，允許你用來開檔案的 App（例如瀏覽器、LINE 或「我的檔案」）。
2. 打開 Pinpins，允許定位和通知。

更新時直接安裝新版覆蓋，資料都會留著。

## 第一次設定（只要一次）

Pinpins 要設成手機的「模擬位置應用程式」才能飛。第一次打開會提醒，照著做就好：

- 設定 → 關於手機 →（三星多一層「軟體資訊」）→ 連按「版本號碼」7 次（打開開發人員選項）
- 設定 → 開發人員選項 → 選取模擬位置應用程式 → Pinpins

用懸浮視窗（跳躍、種花、定點的懸浮工具）或懸浮收集時，要允許「顯示在其他應用程式上層」。開關按不下去（顯示「受限制的設定」，Pixel 等手機常見）：

- 先試著打開一次 → 設定 → 應用程式 → Pinpins → 右上角 ⋮ →「允許受限制的設定」→ 再回去打開

## 飛行

- 輸入一個座標 = 直飛定點；定點中輸入另一個座標，主鍵變成「換位置」，直接瞬移
- 長按地圖：選點（飛過去，或加入輸入框）
- 多點有三種飛法（右側按鈕）：
  - 🎮 跳躍：用懸浮視窗手動一點一點跳
  - 🌸 種花：自動繞著花點循環（點都在 5 公里內會自動選這個）；雙擊 🌸 可以改繞法
  - -1-2- 照順序：照輸入的順序、用走路速度循環
- 跳躍懸浮視窗：點中間的圓點展開面板（最下面一行左邊是鎖定、右邊是複製並記下）；拖到下面的 🗑 只關視窗，不會停飛
- 🔒 鎖定：把位置固定在某個時區的基地，配合遊戲的日期；雙擊鎖定鍵可以改設定
- 左上 ✏️：在地圖上手繪路線；＋ 插入打開後先點一個點、再點地圖，新的點加在它後面；橡皮擦點一下刪掉那一點；↶ 退回上一步
- 飛行中的小停止鍵太小：左側選單「⚙️ 系統 → 🖥️ 顯示」改成中或大

## 懸浮工具與搖桿

種花、照順序、定點起飛時自動出現。

- 🧰 單擊打開第 1 組按鈕、雙擊打開第 2 組（預設是訪花和搖桿），再單擊收起
- 按住 🧰 拖曳；拖到下面的 🗑 就關閉（不會停飛，點通知叫回來）。搖桿按住左上角的四向箭頭拖曳，拖到 🗑 就收起
- 搖桿：推到外圈就往那個方向一直走（上方 N = 北），移回中間才停；快速點中間 2 下切換成「放手就停」，再點 2 下切回來
- 種花、照順序：暫停時才會出現搖桿；按 ▶ 繼續會回到暫停的地方接著走
- 📋 剪貼：選分類、打名稱與備註、📷 選照片，再選 📋 記到剪貼簿 或 💾 存進我的座標；名稱空白會自動用地名命名
- 🌸 訪花（種花時）：點路線圖上的花點選要補繞的，按「開始補繞」就跳過去各繞一圈，繞完回到原本的路線
- 🔍 對齊：遊戲切到俯瞰、地圖轉回北方；按花的圖示後拖曳、雙指縮放，讓路線圖和遊戲的花點重疊，再點花點；按地圖圖示可以操作底下的遊戲
- 按鈕放哪一組、外觀、速度檔位：左側選單「🕹️ 懸浮工具」

## 我的座標／我的路徑

- 多點按 💾 儲存：可以存成路徑，或存成多筆座標（⚡ 自動選一次類別、✍️ 手動一筆一筆填）
- 按「選取」後可以「✏️ 改名」：依地名重新編號，或自己取名字自動加 #1、#2…
- 選 🍄‍🟫 藏菇後，下面可以再篩燈號和風險，可以多選
- 匯入路徑檔時，可以選「📍 單筆座標」存成我的座標；路徑的「編輯」裡可以把 🌸 種花／〰️ 其他互換
- 路徑卡片 ⋮「⏰ 倒數計時」：選 23 小時或自訂時間，也可以選「🔔 時間到時發出聲音」；卡片上 🔔 = 會響、⏳ = 不響
- 裡面「範例」開頭的點和路徑可以直接拿來試飛，不要時刪掉就好

## 小技巧

- **收集別人分享的座標**：左側選單 → 📋 剪貼簿 → 📥 懸浮收集。在 LINE 等 App 複製座標後，按一下懸浮鈕就收進來
- **減少位置閃回**：左側選單「📡 防止閃回」→ 關掉「Google 定位精確度」（最有效）；「Wi-Fi 掃描」「藍牙掃描」也可以關。需要導航時再打開
- **換手機**：左側選單 → ⚙️ 系統 → 💾 備份與還原 → 建立備份；新手機裝好 Pinpins 後選「從備份還原」
